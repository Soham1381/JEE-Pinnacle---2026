1.  **Clone the Repository**:
    ```bash
    git clone [https://github.com/Soham1381/JEE-Pinnacle---2026.git](https://github.com/Soham1381/JEE-Pinnacle---2026.git)
    ```
2.  **API Configuration**:
    *   Open `index.html`.
    *   In the `callClaude` function, ensure your API endpoint and keys are correctly configured for the Anthropic integration[cite: 6].
3.  **Launch**:
    Open `index.html` in any modern web browser—no build tools or complex dependencies required[cite: 6].
